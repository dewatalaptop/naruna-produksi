Naruna Produksi

Aplikasi Android untuk operator stasiun — pindai tiket kerja, catat masuk/keluar, tanpa perlu kertas.

⬇ Unduh Aplikasi (APK)

Untuk tablet/HP Android versi 7.0 ke atas. Ukuran file sekitar 33 MB.

Sebelum mulai

  • Akun stasiun (username & password) harus sudah dibuat oleh admin lebih dulu, lewat menu Master Data → Akun Stasiun di aplikasi web ini. Aplikasi Android tidak bisa dipakai untuk mendaftar sendiri.
  • Tablet/HP terhubung internet saat instal dan login pertama kali. Setelah itu, aplikasi tetap bisa dipakai sementara tidak ada internet — lihat bagian "Indikator penting" di bawah.

1 Cara Instal

  1. Buka halaman ini di tablet stasiun, lalu tekan tombol Unduh Aplikasi (APK) di atas.
  2. Setelah selesai terunduh, buka file app-debug.apk dari notifikasi unduhan, atau dari folder Unduhan/Downloads.
  3. Kalau muncul peringatan "Untuk keamananmu, HP tidak diizinkan menginstal aplikasi tidak dikenal dari sumber ini" — ini normal, karena aplikasi belum ada di Play Store. Tekan Setelan, aktifkan Izinkan dari sumber ini, lalu tekan tombol kembali dan tekan Instal lagi.
  4. Tunggu sampai proses instal selesai, lalu tekan Buka.

2 Login Pertama Kali

  1. Masukkan Username yang diberikan admin (biasanya nama stasiun, contoh: painting).
  2. Masukkan Password yang diberikan admin.
  3. Tekan Masuk.

Setelah berhasil, aplikasi akan tetap login di tablet ini — tidak perlu login ulang setiap hari, kecuali memang ingin ganti akun (lihat bagian bawah).

3 Pakai Sehari-hari

  • Melihat antrean — daftar tiket kerja yang menunggu di stasiun ini muncul otomatis di layar utama, sudah diurutkan dari yang paling mendesak duluan.
  • Memindai QR — tekan tombol bulat Pindai QR di pojok kanan bawah, lalu arahkan kamera ke QR code yang tertempel di tiket kerja.
  • Kalau QR rusak/tidak terbaca — ketik ID tiket secara manual di kolom bagian bawah layar kamera, lalu tekan Cari.
  • Tiket baru tiba (scan MASUK) — layar akan menampilkan kartu konfirmasi "Konfirmasi tiket MASUK". Tekan Konfirmasi.
  • Pekerjaan selesai (scan KELUAR) — isi kolom Jumlah (dan Susut jika ada barang cacat/pecah), lalu tekan Konfirmasi.
  • Kalau muncul tulisan merah "Tiket ini seharusnya berada di stasiun lain" — pastikan dulu memang benar tiket itu yang mau diproses sebelum lanjut menekan Konfirmasi.
  • Bisa juga tekan langsung salah satu tiket di daftar antrean tanpa perlu memindai kamera.

Indikator Penting di Layar

Online (titik hijau) — tersambung internet, data langsung tersimpan ke server.
Offline (titik merah) — tidak ada internet. Jangan khawatir, data tetap aman tersimpan di tablet dan akan otomatis terkirim begitu internet tersambung lagi.

Tulisan kecil seperti "3 belum tersinkron" menunjukkan jumlah catatan scan yang masih menunggu terkirim ke server — ini akan hilang sendiri begitu terkirim.

Ganti Akun / Tablet Dipindah ke Stasiun Lain

Tekan menu titik tiga di pojok kanan atas, pilih Ganti Akun, lalu login dengan akun stasiun yang baru.

Kalau Ada Masalah

Kamera tidak menyala saat memindai

Pastikan sudah menekan "Izinkan" saat aplikasi pertama kali meminta akses Kamera. Kalau tertolak, buka Setelan HP → Aplikasi → Naruna Produksi → Izin, lalu aktifkan Kamera.

Notifikasi peringatan tenggat tidak muncul

Buka Setelan HP → Aplikasi → Naruna Produksi → Izin, lalu aktifkan Notifikasi.

Lupa username/password

Minta admin untuk reset password lewat menu Master Data → Akun Stasiun di aplikasi web ini.

Antrean tiket kosong padahal seharusnya ada

Kemungkinan Purchase Order atau data Item terkait belum dibuat admin di aplikasi web, atau tiket itu memang belum sampai giliran stasiun ini.
